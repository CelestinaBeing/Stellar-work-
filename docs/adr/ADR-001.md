# ADR-001: Use Soroban smart contracts for escrow logic

**Status:** Accepted
**Date:** 2026-06-30

## Context
We need a secure, trustless way to lock funds between a client and a freelancer, only releasing them when agreed-upon conditions are met (or via dispute resolution).

## Decision
We will use Stellar's Soroban smart contracts for the escrow logic. Soroban provides a Rust-based, efficient, and developer-friendly environment natively integrated with the Stellar network.

## Consequences
- **Easier:** Direct integration with Stellar assets, high performance.
- **Harder:** Learning curve for Rust/Soroban compared to Solidity; tooling is still maturing compared to EVM ecosystem.
