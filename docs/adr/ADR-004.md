# ADR-004: Description storage using on-chain hash + off-chain resolution

**Status:** Accepted
**Date:** 2026-06-30

## Context
Storing full job descriptions and details on-chain is prohibitively expensive due to storage costs on the Stellar network.

## Decision
We will store only a 32-byte hash (e.g., IPFS CID hash) of the job description on-chain. The actual content will be stored off-chain (e.g., IPFS or a centralized database) and resolved by the frontend using the hash.

## Consequences
- **Easier:** Keeps contract storage minimal and cheap.
- **Harder:** Requires robust off-chain storage and availability guarantees; frontend must handle asynchronous resolution.
