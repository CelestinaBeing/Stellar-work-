# ADR-002: Use Next.js App Router for frontend architecture

**Status:** Accepted
**Date:** 2026-06-30

## Context
We need a modern, scalable, and SEO-friendly frontend architecture for the web application.

## Decision
We will use Next.js with the App Router. The App Router provides server-side rendering, streaming, and nested layouts, which fit our requirements well.

## Consequences
- **Easier:** Building complex layouts, data fetching on the server, SEO optimization.
- **Harder:** Migration from older React patterns (if applicable), slightly steeper learning curve for server vs client components.
