# ADR-003: Use Freighter as primary wallet integration

**Status:** Accepted
**Date:** 2026-06-30

## Context
Users need to sign Soroban transactions and interact with the platform using a browser-based wallet.

## Decision
We will integrate Freighter as the primary wallet. Freighter is purpose-built for the Stellar network and natively supports Soroban contract invocations.

## Consequences
- **Easier:** Seamless Soroban integration, high reliability on Stellar.
- **Harder:** Limits users who prefer other wallets until multi-wallet support is added.
