# ADR-005: Single-admin model with planned upgrade to multi-sig

**Status:** Accepted
**Date:** 2026-06-30

## Context
The smart contract requires an admin role for upgrades, fee parameter adjustments, and dispute resolution. 

## Decision
We will launch with a single-admin model (a single Stellar address controls the contract). We plan to upgrade to a multi-sig (multi-signature) model in the future to improve security and decentralize control.

## Consequences
- **Easier:** Fast iteration and simple deployment in the initial stages.
- **Harder:** Single point of failure initially; requires a migration process later.
